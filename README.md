# Smart Grid Energy Monitoring & Analytics Platform

A real-time smart grid monitoring and analytics platform built using Streamlit and Machine Learning for anomaly detection, renewable energy analysis, and intelligent alert monitoring.

---

## Overview

This project focuses on real-time visualization and analysis of smart grid parameters including voltage, current, temperature, power factor, frequency, power consumption, and renewable energy contribution.

The platform integrates interactive dashboards, machine learning-based anomaly detection, and severity-based alert systems to support intelligent monitoring and analytics workflows.

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/smart-grid-analytics-dashboard.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the dashboard:

```bash
streamlit run app.py
```
